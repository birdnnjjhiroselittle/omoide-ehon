# 📖 おもいでえほん

じいじ・ばあばの情報や口ぐせを入力するだけで、**時代背景つきの絵本・アニメ**になる「祖父母の自伝」Webサービスのプロトタイプです。
孫が「自分が生まれる前、おじいちゃん・おばあちゃんはどんな人で、どんな時代を生きていたのか」を知るきっかけをつくります。

🌐 デモ: https://birdnnjjhiroselittle.github.io/omoide-ehon/

## できること
- **かんたん入力**：生まれ年・出身地・仕事・性格・思い出（「1964 東京オリンピックを見た」形式）・口ぐせ。🎤 音声入力にも対応
- **時代背景を自動挿入**：生まれ年や思い出の年から、戦争・復興・高度経済成長・バブル・平成・令和などの時代と出来事を文章に織り込み
- **メタファー表現 3段階**：そのまま（史実）／たとえ＋解説／たとえだけ（おとぎ話風）
- **キャラクター変更**：ひと／くま／ふくろう／ねこ／大きな木。年齢で見た目も変化
- **画風・語り口**：水彩・クレヨン・セピア写真風／えほん・むかしばなし
- **3つの出力**：📖 絵本（文章を直接編集可）・🎬 アニメ（動く絵＋読み上げ＋字幕の自動再生）・🕰 年表
- 🖨 PDF保存／印刷、入力内容はブラウザに自動保存

## 使い方
`index.html` をブラウザで開くだけ（サーバー・APIキー不要）。
